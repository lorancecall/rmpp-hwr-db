손글씨 공개 데이터셋에 참여하기

reMarkable Paper Pro로 쓴 한국어·영어·숫자 손글씨를 모아, 누구나 쓸 수 있는 손글씨 인식 데이터와 모델을 만듭니다.

무엇을 모으나요?

정해진 연습 페이지에 직접 쓴 손글씨를 펜 획 그대로(좌표, 압력, 굵기) 모읍니다. 연습 페이지는 네 가지입니다.

페이지쓰는 방법
칸 쓰기십자선이 있는 칸에 한 글자씩. 칸 크기가 줄마다 달라 다양한 글씨 크기를 모읍니다.
숫자·기호숫자, 날짜, 금액, 그리고 비슷하게 생긴 글자(0 O ㅇ, 1 l ㅣ 등)를 칸에 씁니다.
영어 4선영어 문장을 네 줄 가이드에 맞춰 씁니다.
자유 줄기준선 위에 자연스럽게 씁니다. 일부 줄은 평소 메모하듯 빠르게.

칸마다 어떤 글자를 썼는지 알기 때문에 글자 단위로도, 줄 단위로도 학습에 쓸 수 있습니다.

언어

노트 하나는 내 언어 + 영어 + 숫자를 함께 연습합니다 (영어 사용자는 영어 + 숫자). 데이터도 언어마다 data/<언어 코드>/ 폴더에 따로 모입니다. 지금은 한국어(ko)와 영어(en)를 지원합니다 (languages.json). 언어마다 이 사이트에 자기 페이지가 있습니다 (맨 위 메뉴, 기본은 영어).

다른 언어로 참여하고 싶다면 언어 추가 요청 양식으로 알려 주세요. 연습 문장(퍼블릭 도메인이나 공개 라이선스)과 문자 범위가 정해지면 그 언어의 연습 페이지와 폴더를 만듭니다.

개인정보

  • 데이터에는 무작위 작성자 ID, 연습 템플릿, 펜 획만 들어갑니다. 이름, 계정, 기기 정보, 문서 이름, 작성 시각은 들어가지 않습니다.
  • 연습 페이지에 인쇄된 문장만 따라 씁니다. 개인 노트는 절대 올라가지 않습니다.
  • 모든 제출은 자동 검사를 거칩니다. 허용된 항목만 있는지, 이메일·URL·전화번호 같은 패턴이 없는지 확인합니다.
  • 단, 참여 신청 이슈와 Pull Request를 연 GitHub 계정은 공개됩니다. 원하면 이 프로젝트용 GitHub 계정을 따로 만들어 참여해도 됩니다.

참여 방법

  1. 준비물 확인 reMarkable Paper Pro (개발자 모드 켜짐), PC (Windows, macOS, Linux), GitHub 계정, GitHub CLI(gh)가 필요합니다. 터미널에서 gh auth login으로 한 번 로그인해 두세요.
  2. rmpp-hwr 설치 태블릿에 rmpp-packages의 rmpp-preload가 있어야 합니다 (vellum add rmpp-preload). 그다음 PC에서: 
    git clone https://github.com/lorancecall/rmpp-hwr
cd rmpp-hwr
cp .env.example .env      # 태블릿 주소 입력
tools/hwr install
    자세한 내용은 rmpp-hwr 설치 안내를 보세요. 태블릿 OS를 업데이트한 뒤에는 tools/hwr install을 한 번 더 실행합니다.
  3. 참여 신청 (동의) 참여 신청 양식에서 동의 항목 5개를 확인하고 이슈를 엽니다. 자동으로 확인 댓글이 달리면 그 이슈 번호를 기억해 두세요.
  4. 연습 노트 받기 
    hwr practice --v2              # 한국어 + 영어 + 숫자
hwr practice --v2 --lang en    # 영어 + 숫자
    태블릿의 hwr-db/<언어> 폴더에 rmpp-practice-v2-… 노트(8페이지)가 생깁니다. 언어는 .env의 HWR_LANG으로 정해 둘 수도 있습니다.
  5. 쓰기 각 페이지 위의 안내대로 씁니다. 칸에는 한 글자씩, 칸 밖으로 크게 넘치지 않게 씁니다. 평소 글씨체 그대로 쓰는 것이 가장 좋습니다. 틀린 글자는 지우개로 지우고 다시 쓰면 됩니다.
  6. 가져오기와 검사 
    hwr pull
hwr qc
    빈 칸이나 옆 칸으로 넘어간 획이 있으면 알려 줍니다. 필요하면 태블릿에서 고친 뒤 다시 hwr pull 합니다.
  7. 제출 
    hwr contribute --consent <이슈 번호>
    처음 한 번만 --consent를 붙입니다. 개인정보를 뺀 데이터로 Pull Request가 자동으로 열리고, 자동 검사를 통과하면 관리자가 확인한 뒤 데이터셋에 합칩니다. 다음부터는 hwr contribute만 실행하면 새로 쓴 페이지만 올라갑니다.

동의 내용 요약

  • 제출한 데이터는 CC BY 4.0으로 공개됩니다. 출처를 밝히면 누구나(상업적 이용 포함) 쓸 수 있습니다.
  • 연습 페이지에 인쇄된 문장만 쓰고, 개인 정보는 쓰지 않습니다.
  • GitHub 계정(이슈, PR 작성자)은 공개됩니다.
  • 만 14세 이상만 참여할 수 있습니다.
  • 철회할 수 있지만, 이미 공개된 이전 버전과 다른 사람이 받아 간 사본은 회수할 수 없습니다.

철회하기

철회 요청 양식으로, 참여 신청 때와 같은 GitHub 계정에서 요청해 주세요. 작성자 ID는 PC의 hwr-data/writer.json에 있습니다. 다음 버전부터 데이터셋과 Hugging Face 미러에서 삭제됩니다.

자주 묻는 질문

글씨를 예쁘게 써야 하나요?

아니요. 평소 글씨 그대로가 가장 도움이 됩니다. 사람마다 다른 글씨를 많이 모으는 것이 목적입니다.

몇 페이지나 써야 하나요?

노트 하나(8페이지)면 충분합니다. 더 써 주시면 더 좋습니다. 매번 새 문장이 나옵니다.

제 손글씨 모델도 좋아지나요?

네. 쓴 페이지는 PC에 남아서 hwr train으로 내 글씨에 맞춘 모델을 만드는 데도 쓰입니다. 공개 모델은 모든 참여자 데이터로 주기적으로 학습해 배포합니다.
