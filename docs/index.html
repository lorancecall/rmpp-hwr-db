What is collected

Handwriting on printed practice pages, stored as pen strokes (coordinates, pressure, width). There are four kinds of pages:

PageHow to write
CellsOne character per cell with a light cross guide (for scripts like Hangul, kana or Chinese characters). Cell sizes change per row, for different writing sizes.
Digits and symbolsNumbers, dates, prices, and look-alike characters (0 O o, 1 l I, ...) in cells.
English four linesEnglish sentences on four guide lines.
Free linesNatural writing on a baseline; some lines quickly, like everyday notes.

Every cell and line carries the text that was printed, so the data works for character-level and line-level training.

Languages

Each practice notebook mixes your language + English + digits (English writers: English + digits), and the data of each language lives in its own folder data/<code>/. Supported languages are in languages.json; choosing one at the top shows this page in that language.

Your language is missing? Ask for it with the "Add a language" form (or "My language isn't listed" at the top). Once the characters and the practice texts (newly written or public domain) are settled, the language gets its practice pages and its data folder, and it can be chosen on this page.

Privacy

  • The data holds a random writer id, the practice template and the pen strokes. No names, accounts, device information, document names or times.
  • Only the sentences printed on the practice pages are written; personal notes are never uploaded.
  • Every submission is checked automatically: only allowed fields, and no patterns like e-mail addresses, URLs or phone numbers.
  • The GitHub account that opens the join issue and the pull request is public. You can make a separate GitHub account for this project.

How to take part

  1. What you need A reMarkable Paper Pro with developer mode on, a computer (Windows, macOS, Linux), a GitHub account and the GitHub CLI (gh). Log in once with gh auth login.
  2. Install rmpp-hwr The tablet needs rmpp-preload from rmpp-packages (vellum add rmpp-preload). Then on the computer: 
    git clone https://github.com/lorancecall/rmpp-hwr
cd rmpp-hwr
cp .env.example .env      # the tablet's address, your language (HWR_LANG)
tools/hwr install
    Details: rmpp-hwr install guide. Run tools/hwr install again after a tablet OS update.
  3. Join (consent) Open the join form for your language (pick it at the top of the page) and tick the five consent items. When the confirmation comment appears, note the issue number.
  4. Get a practice notebook 
    hwr practice --v2 --lang en    # English + digits
hwr practice --v2 --lang ko    # Korean + English + digits
    A notebook rmpp-practice-v2-… (8 pages) appears in the tablet folder hwr-db/<language>.
  5. Write Follow the line at the top of each page: one character per cell, not far outside it. Your usual handwriting helps most. Erase and rewrite mistakes.
  6. Collect and check 
    hwr pull
hwr qc
    It reports empty cells or strokes that run into the next cell; fix them on the tablet and pull again.
  7. Submit 
    hwr contribute --consent <issue number>
    --consent is needed the first time only. A pull request with the anonymized pages opens automatically; after the checks pass, a maintainer merges it. Later, hwr contribute sends only new pages.

Consent in short

  • Submitted data is published under CC BY 4.0: anyone may use it (also commercially) with attribution.
  • Write only the printed sentences, no personal information.
  • Your GitHub account (issue and pull request author) is public.
  • Participants must be at least 14 years old.
  • You can withdraw, but published earlier versions and copies others downloaded cannot be recalled.

Withdraw

Use the withdraw form from the same GitHub account as your join issue. Your writer id is in hwr-data/writer.json on your computer. Your data is removed from the next version of the dataset and of the Hugging Face mirror.

Questions

Does my handwriting have to be neat?

No. Your everyday handwriting helps most: the point is many different hands.

How much should I write?

One notebook (8 pages) is plenty; more is welcome. Every notebook has new sentences.

Does it improve my own model too?

Yes. Your pages stay on your computer, and hwr train uses them for a model tuned to your handwriting. The public model is trained regularly on everyone's data.
